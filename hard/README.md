## 0042. Trapping Rain Water
**Ссылка на задачу:** https://leetcode.com/problems/trapping-rain-water/

## Подход

Для решения задачи я использовал алгоритм «двух указателей». Два указателя - `left` и `right` идут по массиву навстречу друг другу, пока не встретятся. На каждом шаге мы выбираем сторону, с 
которой будем работать, ориентируясь на меньший из двух крайних столбиков. Рассмотрим логику на примере левой стороны:
```cpp
while (left < right) {
    if (height[left] < height[right]) {
        // здесь левая сторона
        if (height[left] >= left_max) {
            left_max = height[left];
        } else {
            max_water += left_max - height[left];
        }
        ++left;
    } else { . . . }
}
```
Мы сравниваем текущий столбец `height[left]` с максимальной стеной, которую встретили слева до этого (`left_max`). Если текущий столбец выше или равен `left_max`, он становится нашей новой 
левой стеной-ограничителем и обновляем `left_max`. Вода тут скопиться не может, если текущий столбец ниже, то между ним и левой стеной гарантированно образуется «яма». Мы прибавляем разницу 
`left_max - height[left]` к общему объёму `max_water` и сдвигаем указатель дальше.

## Сложность

- Время: O(n) - размер массива `height`.
- Память: O(1)
