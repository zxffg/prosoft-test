## 0048. Rotate image
**Ссылка на задачу:** https://leetcode.com/problems/rotate-image/

### Подход

Для начала воспользуемся математическим приемом под названием транспонирование - где строки становятся столбцами. Во вложенном цикле функция `swap` 
меняет местами элементы `matrix[i][j]` и `matrix[j][i]`. Внутренний цикл начинается с `j = i + 1`. Это позволяет обрабатывать элементы выше 
главной диагонали. Если бы `j` начинался с `0`, мы бы сначала поменяли элементы местами, а затем вернули их в исходное положение.
И в конце разворот строк: проходим по каждой строке матрицы и с помощью стандартной функции `reverse` переворачиваем элементы задом наперёд.

### Сложность

- Время: O(n**2) - количество строк/столбцов
- Память: O(1)

## 0003. Longest Substring Without Repeating Characters 
**Ссылка на задачу:** https://leetcode.com/problems/longest-substring-without-repeating-characters/

### Подход

Решение заключается в том же алгоритме "скользяящее окно", как и в задаче [0121](../easy/0121-best-time.cpp). Алгоритм использует два указателя (`left` и 
`right`), которые двигаются слева направо: `right` на каждом шаге расширяет окно, забирая новый символ. Массив `last_pos` помнит последний индекс каждого 
символа. Если символ уже есть в окне, `left` мгновенно прыгает за его предыдущую позицию, удаляя дубликат. На каждом шаге считается длина окна: `right - 
left + 1`, а лучший результат сохраняется в `max_size`.

### Сложность

- Время: O(n) - длина массива s
- Память: O(1)
