## 0020 - Valid parentheses
**Ссылка на задачу:** https://leetcode.com/problems/valid-parentheses/

### Подход

На самом деле, решение сводится к реализации алгоритма на основе стека. По условию: "открывающие скобки должны быть закрыты скобками того же типа;". Это 
значит, что контейнер (в данном случае стек) поочередно помещает в себя все встречающиеся скобки. Как только скрипт встречает закрывающую скобку, 
инициируется проверка:
```cpp
    switch (s[i]) {
        case ')': 
            if (!st.empty() && st.top() == '(') { st.pop(); } 
            else { return false; }
            break;
        . . .
    }
``` 
"если контейнер не пустой и верхний элемент равен открывающей скобке того типа, который проверяется, то удали последний добавленный элемент или верни 
`false` (при несовпадении условий)"
В качестве контейнера был выбран стек, так как он работает по принципу Last In First Out - элемент добавленный последним, будет получен в первую очередь.

### Сложность

- Время: O(n)
- Память: O(n)
где n - длина строки.

## 0121 - Best time to buy and sell stock
**Ссылка на задачу:** https://leetcode.com/problems/best-time-to-buy-and-sell-stock/description/

### Подход

Идея заключается в реализации алгоритма "скользящее окно". Указатель `left` указывает на день с минимальной ценой покупки. Указатель `right` указывает на 
день потенциальной продажи и расширяет окно. Условие `prices[right] < prices[left]` указывает на необходимость сдвига левого указателя в позицию right 
для более выгодной покупки. Переменная `max_profit` хранит максимальную прибыль, которая обновляется каждый раз, когда текущая разница цен между покупкой 
и продажей оказывается наивысшей.

### Сложность

- Время: O(n), где n - это количество эл-ов в `prices`
- Память: O(1)
